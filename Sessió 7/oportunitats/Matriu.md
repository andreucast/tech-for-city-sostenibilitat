# MATRIU DAFO



| POSITIUS |  | NEGATIUS |
|---|:---:|---|
| **FORTALESES** | | **DEBILITATS** |
| Existència de contenidors per separar les diferents fraccions de residus. |  | Percentatge de recollida selectiva baix: el 2025 va ser del 26,8%, segons dades publicades per L’Hdigital. |
| Disponibilitat de la deixalleria municipal per gestionar residus especials, voluminosos i altres materials. |  | Gran quantitat de residus que encara es dipositen a la fracció resta. |
| Existència d’una ordenança municipal que regula la gestió dels residus. |  | Possibles errors de separació dels residus i presència d’impropis als contenidors. |
| Possibilitat d’implicar escoles, associacions veïnals, comerços i entitats locals. |  | Dificultat per mantenir els carrers nets quan s’acumulen deixalles fora dels contenidors. |
| **OPORTUNITATS** | | **AMENACES** |
| Ajuts i programes supramunicipals per impulsar projectes de sostenibilitat i economia circular. |  | Alta densitat de població i elevada concentració d’habitatges, que dificulten l’adaptació dels sistemes de recollida. |
| Noves tecnologies per optimitzar les rutes de recollida i detectar contenidors plens. | | Increment dels costos de recollida, transport i tractament dels residus. |
| Implantació de sistemes més eficients, com els contenidors tancats identificats o la recollida porta a porta en zones adequades. |  | Manca de participació ciutadana o resistència a canviar els hàbits de consum i reciclatge. |
| Col·laboració amb empreses, comerços i entitats per reduir els envasos i el malbaratament alimentari. |  | Augment dels residus d’un sol ús i dels envasos. |

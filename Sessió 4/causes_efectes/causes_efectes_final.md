## CAUSES I EFECTES FINAL

| CAUSES |  | EFECTES |
|---|---|---|
| **CAUSES IMMEDIATES** | | **EFECTES IMMEDIATS** |
| Deixar bosses d'escombraries i mobles fora dels contenidors perquè no es dipositen al lloc adequat. |  | Acumulació de residus als carrers, males olors i brutícia al voltant dels contenidors. |
| Contenidors plens o falta de contenidors de reciclatge. |  | Les persones poden deixar més residus fora dels contenidors, cosa que empitjora la neteja dels carrers. |
| Separar incorrectament els residus o barrejar diferents materials. |  | Es dificulta el reciclatge i es perden materials que es podrien reutilitzar. |
| Desconèixer on s'han de portar els mobles i els objectes voluminosos. |  | Els mobles i altres objectes s'acumulen a la via pública i dificulten el pas dels vianants. |
| **CAUSES A LLARG TERMINI** | | **EFECTES A LLARG TERMINI** |
| Falta d'hàbits de reciclatge i poca conscienciació ambiental. |  | Es recicla menys i augmenta la quantitat de residus que acaben als abocadors. |
| Falta d'educació ambiental continuada sobre la separació i la gestió dels residus. |  | Es poden mantenir els mals hàbits i augmentar la quantitat de residus mal gestionats. |
| Planificació insuficient de la recollida de residus i dels contenidors disponibles. | | L'acumulació de residus pot continuar al llarg del temps i empitjorar la qualitat de vida dels veïns. |
| Mala gestió continuada dels residus i poca separació dels materials reciclables. |  | Pot augmentar la contaminació del sòl i de l'aigua, provocar danys als ecosistemes i afectar els animals. |
